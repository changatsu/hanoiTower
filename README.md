# ハノイの塔

ブラウザで遊べるハノイの塔パズルです。React + Vite で作られた静的サイトで、データベースやサーバーは使いません。

**遊ぶ:** https://changatsu.github.io/hanoiTower/

## ルール

左の柱（A）に積まれた円盤をすべて右の柱（C）へ移すとクリアです。

- 一度に動かせるのは一番上の円盤 1 枚だけです。
- 小さい円盤の上に大きい円盤は置けません。
- 円盤が n 枚のとき、最少手数は 2ⁿ − 1 手です。

## 遊び方

- 柱をタップ（クリック）して一番上の円盤を持ち上げ、置きたい柱をタップします。
- 円盤をドラッグして別の柱に落としても動かせます。
- キーボードでは Tab で柱を選び、Enter / Space で持ち上げと配置ができます。
- 円盤は 3〜10 枚から選べます。
- 「1手戻す」「最初から」「お手本を見る」（最短手順の自動再生）ボタンがあります。
- 円盤の枚数ごとの自己ベストはブラウザの localStorage に保存されます。

## ねこだな（ねこの色仕分けパズル）

同じリポジトリに、棚に並んだねこを色ごとに仕分けるパズル「ねこだな」も入っています。

**遊ぶ:** https://changatsu.github.io/hanoiTower/neko/

- 棚は左右 2 列で、真ん中の通路側が「先頭」です（左の棚は右端、右の棚は左端）。棚をタップすると、先頭のねこ（と、そのすぐ後ろに続く同じ色のねこ）を持ち上げます。
- 置けるのは、先頭に同じ色のねこがいる棚か、空いている棚だけです。棚に入りきる分だけ移ります。
- 「？」のねこは、先頭に来るまで色がわかりません。
- すべての棚が 1 色ずつで満杯（または空）になればクリアです。
- 初級・中級・上級の 3 レベルに、それぞれ 12 ステージ（全 36 ステージ）。ステージが進むほど色の数と「？」の割合が増えます（棚の長さは 4 匹で固定）。ステージは順番に解放され、ステージ名をタップするとステージ選択画面が開きます。どのステージも、全部見えていれば解ける配置になるように自動生成して確認しています。
- 超上級（12 ステージ）は 9 色・空き棚 2 のまま「？」が 70% から増え、ステージ12 では先頭以外すべて「？」。超上級ステージ12 をクリアするとエンドレスが開放され、超上級12 と同じ難しさで超上級ステージ13、14 … と毎回ちがう盤面が続きます。ステージ番号がそのまま続けた回数になります。
- ★の評価：クリアした手数で★1〜3。★3 の目標は「全部見えていれば何手で解けるか」の最短手数（自動計算）に、「？」の数の 1/3 を足した手数。★2 はさらにその 3 割増しまで。ステージ選択に各ステージの★が出ます。
- 今日の1問：日付で決まる 1 日 1 問（ステージ選択のいちばん上）。曜日で難しさが変わり、月曜がやさしく日曜がいちばん難しい。何日続けて解いたかを数え、★と一緒に LINE で送れます。まだ解いていない日は、操作行のステージ名に赤い印が付きます。
- ヒント：タイトル行の 💡 で、次の正しい 1 手を光らせます（1 日 3 回まで。数字は今日の残り）。
- タイムアタック：ステージ選択から。3 分で何問解けるかを競います。4 色から始まり、2 問ごとに色が増えます。
- きせかえ（ねこ図鑑）：ステージ選択の「👒 きせかえ」から。★の合計、今日の1問の連続日数、タイムアタックの記録で、リボン・おはな・マフラー・まるめがね・ほしのかみかざり・シルクハット・おうかんが手に入り、ねこたちに身につけさせられます。
- 特別なねこ：中級ステージ7 から出てきます。ねぼすけねこ（Zz）は先頭に来ても眠っていて、タップして起こすと（1 手）動かせます。どっしりねこ（重）は 1 匹ずつしか動きません。初めて出てきたときに説明が出ます。★の目標手数には、その分の余裕を足しています。
- 隠し要素：タイトル「ねこだな」を素早く 7 回タップすると、超上級ステージ12 まで全ステージとエンドレスが開放されます（自己ベストは記録されません）。
- 首輪のしるし（●▲■★…）で、色の見分けがつきにくくても区別できます。
- 「説明」ボタンで操作の説明文の表示を切り替えられます（最初はオフ）。
- 効果音があります（選ぶ・置く〈色ごとに高さの違う鳴き声〉・？の色がわかる・置けない・1手戻す・棚がそろう・クリア）。「音」ボタンでオン／オフでき（最初はオン）、iPhone ではマナーモード中は鳴りません。
- クリアすると、完成した棚の画像とレベル・ステージ・手数を「LINEで送る」ボタンで共有できます（スマホの共有シートから LINE を選ぶ。共有シートが使えない環境では LINE の文字だけの共有を開く）。
- 進んだステージ、各ステージの自己ベスト、説明と音の設定はブラウザの localStorage に保存されます。

## 開発

Node.js 22 以降を想定しています。

```sh
npm install
npm run dev      # 開発サーバー
npm test         # ゲームロジックのテスト（node:test）
npm run build    # dist/ に静的ファイルを出力
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/hanoi.js` | ゲームロジック（移動判定、クリア判定、最短手順）。UI に依存しない純粋関数 |
| `src/App.jsx` | 画面全体と状態管理（手数、履歴、お手本再生、自己ベスト） |
| `src/Board.jsx` | 盤面の描画とタップ／ドラッグ操作 |
| `src/styles.css` | スタイル（ライト／ダーク対応） |
| `test/hanoi.test.js` | ロジックのテスト |
| `neko/index.html` | ねこだなのページ |
| `src/neko/logic.js` | ねこだなのロジック（移動判定、？の公開、クリア判定、面の生成と解けるかの確認） |
| `src/neko/sound.js` | 効果音（Web Audio API でその場で合成。音源ファイルなし） |
| `src/neko/share.js` | クリアした盤面の共有画像（SVG → PNG）を作り、共有シート／LINE で送る |
| `src/neko/App.jsx` / `Cat.jsx` / `neko.css` | ねこだなの画面、ねこのイラスト（SVG）、スタイル |
| `test/neko.test.js` | ねこだなのロジックのテスト |

## 公開

`main` ブランチに push すると GitHub Actions（`.github/workflows/deploy.yml`）がテストとビルドを行い、GitHub Pages に公開します。初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
